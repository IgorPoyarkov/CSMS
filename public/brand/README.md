# CSMS — фирменный знак

Система управления контрактной службой заказчика.
Владелец: ИП, ИНН 462302564694.

## Идея

Шрифтовая часть — аббревиатура **КСЗ**: Контрактная Служба Заказчика.
Она выводится из названия системы и раскрывается полной подписью
«Система управления контрактной службой заказчика».

Знак — строгая монограмма «К» в плитке:

- вертикальная стойка и диагонали — контракт (К);
- верхняя полка — лист документа и строка регламента;
- нижняя ножка — скрепление дела.

Никаких мелких деталей: знак читается от 16 px, узнаётся без подписи.
Палитра и характер — из интерфейса: глубокий зелёный, мята, шалфей.

## Правила

- Охранное поле вокруг логотипа — не меньше высоты знака.
- Минимальный размер: знак — 16 px, горизонтальный логотип — 120 px по ширине.
- Не менять пропорции, не перекрашивать вне палитры, не добавлять тени,
  обводки и градиенты на текст.
- На фотографиях и сложном фоне использовать монохромную версию.

## Технические детали

- Все надписи переведены в кривые: SVG не зависит от установленных шрифтов.
- Пропорции и охранные поля заданы в `viewBox`, файлы масштабируются без потерь.
- PNG подготовлены с альфа-каналом (32-bit ARGB).
