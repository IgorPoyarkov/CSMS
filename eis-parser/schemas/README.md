# XSD-схемы ЕИС 44-ФЗ

Положить актуальные XSD из Альбома ТФФ в `schemas/Schemas44/`:

- базовые типы: `BaseTypes.xsd`, `CommonTypes.xsd`;
- извещения 2020+: `epNotificationEF2020.xsd`, `epNotificationEOK2020.xsd`,
  `epNotificationEZK2020.xsd`;
- контракты и протоколы: `contract.xsd`, `epProtocol...xsd`.

После добавления/обновления схем запустить `./generate-models.ps1` из этой
папки. Скрипт генерирует C#-модели через `dotnet-xscgen` — устаревший
`xsd.exe` падает на перекрёстных импортах ЕИС.

Сгенерированные классы изолированы в отдельном пространстве имён с привязкой
к версии Альбома форматов. Бизнес-логика и DTO фронтенда не зависят от них
напрямую: связь идёт только через слой мапперов.
